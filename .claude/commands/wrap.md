# /wrap — 세션 마무리

세션을 닫기 전 산출물을 정리하고 복구 지점(커밋)을 만든다. **자동 커밋 금지 — 반드시 사용자 승인 후.**

## 실행 흐름

### Step 1: 세션 요약
이번 세션에서 한 작업·결정·미완 항목을 3~7줄로 요약해 보여준다.

### Step 2: 변경이력 갱신
핵심 메타파일(CLAUDE.md, 커맨드, 룰)을 수정했다면 `_meta/changelog.md`에 한 줄 추가하고,
CLAUDE.md `## 변경 이력`은 최근 3행만 유지한다.

### Step 3: PII 게이트
`git status --porcelain`으로 변경 파일 목록을 뽑아 PII/시크릿 의심 패턴
(.pem/.key, secret, credential, 통장/계좌/주민/계약서 등)이 있으면 **커밋을 중단**하고
.gitignore 보강을 먼저 제안한다.

### Step 4: diff 요약 + 사용자 승인
변경 파일 목록과 핵심 diff를 요약해 보여주고 커밋 여부를 묻는다. 승인 없이 커밋하지 않는다.

### Step 5: 커밋 (세션당 1개)
```bash
git add -A && git commit -m "chore(wrap): {날짜} {세션 주제 한 줄}"
```
push는 사용자가 별도로 요청할 때만.

## 참조
- `_meta/changelog.md` — 변경이력 정본
- `.gitignore` — PII 3중 방어
