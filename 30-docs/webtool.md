# 렌더 웹 툴 사용 가이드 (`webtool/`)

> SketchUp 캡처 → 스타일 팩 선택 → 프롬프트 확인 → 렌더 → 영역 수정(Fix) → 리비전 비교까지를 브라우저 한 화면에서 하는 로컬 도구. 파이프라인 정본은 `scripts/`이고 이 툴은 그 위의 얇은 UI다. 코드 세부·API 표는 `webtool/README.md`.

## 시작

```bash
python3 webtool/server.py
# → http://127.0.0.1:8765 를 브라우저로 연다 (127.0.0.1 전용, 외부 접속 불가)
```

`scripts/`가 아직 없는 환경에서 UI만 보려면 `--stub`을 붙인다. 스텁은 입력 이미지를 그대로 "렌더"로 복사한다.

## 화면 흐름

```
[왼쪽 열]                                  [오른쪽 열]
1. 캡처 드롭/선택  ──▶ assets/captures/P/S/   리비전 탭 R00 R01 R02 …
2. 프로젝트 / 샷                              비교 토글 (슬라이더 | 나란히)
3. 스타일 팩 카드 (샘플 썸네일)                Fix 모드 토글
4. 옵션 (무드·조명·계절·카메라·재질·후보정      ├ 브러시 / 지우개 / 사각 / 크기 / 되돌리기 / 지우기
        엔투라지 토글, keep_fixed, 비율)       ├ 지시문
5. 프롬프트 미리보기 (입력 바꾸면 자동 갱신)     └ [영역 수정 (grok)] → 새 리비전
   [렌더]  [팩으로 저장]
```

1. **캡처**: 드래그앤드롭 또는 클릭. PNG/JPG/WebP. 프로젝트·샷 이름은 영문·숫자·`-`·`_`만. 같은 샷에 다시 올리면 덮어쓴다.
2. **팩 선택**: 카드를 누르면 팩의 슬롯 값이 옵션 셀렉트에 미리 채워진다(어휘에 있는 값만). 빈 셀렉트 = 팩 기본값 그대로.
   옵션 패널 자체는 서버가 `prompt_compose.py --list-options`로 받은 어휘로 만들어지므로, 스크립트에 값이 추가되면 재시작 없이 새로고침만으로 반영된다. 인물 밀도·동작 같은 하위 옵션은 "사람" 토글을 켜야 활성화된다.
3. **옵션 → 프롬프트**: 값이 바뀌면 350ms 뒤 `/api/compose`를 호출해 실제 `prompt_compose.py` 출력이 미리보기에 뜬다. 렌더에 들어가는 프롬프트와 동일하다.
4. **렌더**: 기본 백엔드 gpt. 완료까지 버튼이 잠기고 경과 초가 표시된다(최대 600초). 끝나면 새 리비전 탭이 선택된다.
5. **비교**: 슬라이더(입력 위에 렌더를 겹쳐 드래그) 또는 나란히.
6. **Fix**: Fix 모드를 켜면 현재 리비전 위에 캔버스가 뜬다. 바꿀 부분을 칠하고 지시문을 쓴 뒤 "영역 수정". 기준 리비전 폴더에 `mask_n.png`가 저장되고 `render.py fix`가 새 리비전을 만든다.
7. **팩으로 저장**: 현재 옵션 조합을 `assets/stylepacks/custom-<id>/pack.json`으로 저장. 이후 팩 카드에 나타난다. changelog에 `saved from webtool` 기록.

단축키: `B` 브러시 · `E` 지우개 · `Z` 되돌리기 (텍스트 입력 중에는 동작하지 않음).

## 마스크 의미

- 흰색(255) = **이 부분을 바꿔라**, 검정(0) = 그대로 두라.
- 8-bit grayscale PNG, 기준 렌더와 같은 픽셀 크기. 화면 확대/축소 배율과 무관하게 원본 해상도로 저장된다.
- 브러시 경계는 저장 시 0/255로 이진화된다. 부드러운 경계(feather)·확장(dilate)이 필요하면 `render.py fix --dilate --feather`가 맡는다(현재 UI는 노출하지 않음).
- grok이 요구하는 alpha 채널 형식으로의 변환은 `scripts/mask_convert.py`가 한다. 웹 툴은 내부 표준만 쓴다.

## 한계와 주의

| 항목 | 내용 |
|------|------|
| gpt 경로 마스크 없음 | gpt-image(pumasi `--ref`)는 마스크 입력을 받지 않는다. Fix 버튼은 grok 고정 |
| 동기 렌더 | 요청 1건이 끝날 때까지 응답 대기. 여러 렌더를 동시에 눌러도 서버는 처리하지만 UI는 한 번에 하나만 보낸다 |
| 비용 | gpt 렌더는 구독 경로(pumasi)라 한계비용 0. Fix·grok 렌더는 라우터 호출이라 사용량이 잡힌다(구독 경로, usage는 meta.json에 참고치). grok 출력은 1152×864(4:3) 고정 |
| 팩 저장 범위 | 어휘 셀렉트·토글·keep_fixed만 기록. 자유 문장 슬롯은 원본 팩에서 상속(`source_template`) |
| 파일 서빙 | `renders/`, `assets/`만 읽기 전용으로 노출. 그 외 워크스페이스 파일은 404 |

## 문제 해결

- **503 "prompt_compose.py not found"**: `scripts/` 미설치. 응답의 `expected_path`가 실제 위치.
- **502 "script failed"**: 스크립트 오류. 프롬프트 미리보기/상태줄에 `stderr` 마지막 부분이 그대로 표시된다. 없는 pack id, 라우터 키 미매핑(`insane-router-connect`), Pillow 미설치 등.
- **렌더 버튼이 눌리지 않음**: 팩과 캡처가 둘 다 있어야 한다. 프로젝트/샷을 바꾸면 그 샷의 기존 캡처와 리비전을 다시 읽는다.
- **Fix 결과가 기대와 다름**: 마스크가 너무 작거나 경계가 날카로울 수 있다. 크기를 키우거나 `--dilate`/`--feather`를 CLI로 시험.
- **화면이 깨짐/옛 버전**: 정적 파일은 `no-cache`라 새로고침으로 충분. 서버 코드 변경은 재시작 필요.
